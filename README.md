# TS Akwedukt Kielce — strona klubu triathlonowego (portfolio)

Wersja portfolio strony internetowej klubu triathlonowego TS Akwedukt Kielce.
Dane kontaktowe, adresowe oraz dokumenty prawne (polityka prywatności, regulamin) zostały usunięte lub zastąpione danymi przykładowymi.

## Stack

- [Astro](https://astro.build) — statyczny generator stron
- [Tailwind CSS](https://tailwindcss.com)
- [Tabler Icons](https://tabler.io/icons)
- Aktualności pisane w Markdown (`src/pages/news/*.md`)

## Strony

- Strona główna z aktualnościami
- Historia klubu, o klubie, zarząd
- Trenerzy
- Wyniki zawodników (2025, 2026) i medaliści
- Galeria
- Kontakt z formularzem
- Responsywne menu mobilne

## Uruchomienie

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # build do ./dist
npm run preview
```
